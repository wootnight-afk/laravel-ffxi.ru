1. Обзор
Русскоязычное сообщество игроков Final Fantasy XI (сервер Phoenix).
Реконструкция классического сайта-сообщества 2000-х на современном стеке Laravel с сохранением духа оригинала и добавлением современных UX-практик: фиксированная шапка и футер, светлая/тёмная темы, адаптивность, отдельный админ-контур на Filament.

Источники (скриншоты в docs/design/):
ffxi.ru.png, news.png, gallery.png, players-00.png, players-01.png, login.png, contacts.png.

Приоритет достоверности:

Точно — каркас: фиксированная шапка + фиксированный футер, порядок блоков, состав страниц, набор ролей.

Близко — цветовая гамма (бирюзовый акцент) и общий колорит.

Свободно — типографика деталей, отступы, скругления.

10. Правила и запреты (обновлено)
Шапка и футер — position: fixed, проверка прокруткой обязательна.

body { padding-top: var(--header-height); padding-bottom: var(--footer-height); } — без этого контент уезжает под фиксированные зоны.

Клик по логотипу → главная страница. Всегда.

Клик по hero-баннеру → главная страница.

Кнопка «Авторизация» — в правом краю шапки, не в центре.

Переключатель темы — только одна иконка, текст не пишем.

Картинки — только из public/img_site через asset().

Ноль логики в Blade — данные приходят готовыми из контроллера.

Никаких табличных раскладок — Flex / Grid.

Цвета — только из токенов (см. §3). Сомнение → сверка со скриншотом.

Тёмная тема обязательна для всех новых компонентов: проверять через [data-theme="dark"].

Все тексты на русском, как на оригинале.
