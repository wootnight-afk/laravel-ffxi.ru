# WorkAI — инструкции для проекта

Дополнение к `KODA.md` только для AI-агента, работающего над проектом через IDE WorkAI. Общие правила проекта остаются в `KODA.md`.

## Рабочая директория

Канонический каталог проекта: `/home/skyw/projects/laravel-ffxi.ru`.

Все команды, относящиеся к проекту, выполняй относительно этого каталога. Не полагайся на текущий `pwd`: терминал WorkAI может открываться в родительском каталоге `/home/skyw`.

## Git

Для всех Git-команд явно указывай каталог проекта, например:

- `git -C /home/skyw/projects/laravel-ffxi.ru status --short --branch`
- `git -C /home/skyw/projects/laravel-ffxi.ru branch --show-current`
- `git -C /home/skyw/projects/laravel-ffxi.ru log -1 --format='%H%n%s'`

Перед каждой новой задачей проверь состояние дерева, текущую ветку и HEAD (хеш и сообщение последнего коммита). Учитывай обнаруженные незакоммиченные изменения: не перезаписывай и не удаляй чужую работу, не считай дерево чистым без проверки.

Обычные read-only проверки Git разрешены. Не выполняй `push` без отдельного прямого разрешения пользователя. Без соответствующего разрешения не выполняй `commit`, `pull`, `checkout`, `reset`, `clean`, `stash`, `merge`, `rebase` и другие операции, изменяющие историю или состояние Git.

## Universal Development Harness

Не используй Universal Development Harness для работы над `laravel-ffxi.ru`. Он находится вне проекта и не входит в рабочий процесс этого репозитория.
